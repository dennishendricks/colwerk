## More editor keys

The editor also has these keys:

| Keys                                                   | Action                                      |
| ------------------------------------------------------ | ------------------------------------------- |
| :kbd[ctrl+Space]                                       | Open autocomplete                           |
| :kbd[meta+D]                                           | Select the next occurrence                  |
| :kbd[meta+shift+L]                                     | Select all occurrences                      |
| F3 / :kbd[meta+G], :kbd[shift+F3] / :kbd[meta+shift+G] | Next / previous match                       |
| :kbd[meta+alt+G]                                       | Go to line                                  |
| :kbd[meta+/]                                           | Comment or uncomment lines                  |
| :kbd[alt+↑] / :kbd[alt+↓]                              | Move line up / down                         |
| :kbd[shift+alt+↑] / :kbd[shift+alt+↓]                  | Copy line up / down                         |
| :kbd[shift+meta+K]                                     | Delete line                                 |
| :kbd[meta+\[] / :kbd[meta+\]]                          | Indent less / more                          |
| :kbd[shift+meta+\\]                                    | Jump to the matching bracket                |
| :kbd[meta+Z], :kbd[shift+meta+Z]{other="Ctrl+Y"}       | Undo, redo                                  |
| Esc                                                    | Close autocomplete or search, single cursor |

## Elsewhere

| Where       | Keys             | Action                |
| ----------- | ---------------- | --------------------- |
| Tab bar     | Home / End       | First / last tab      |
| Tab bar     | Enter            | Rename tab            |
| Schema tree | :kbd[meta+F]     | Search loaded objects |
| Result      | :kbd[meta+F]     | Filter the result     |
| Cell editor | :kbd[meta+Enter] | Apply the value       |
