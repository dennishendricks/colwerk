## More editor keys

The editor also has these keys:

| Keys               | Action                                      |
| ------------------ | ------------------------------------------- |
| ⌃Space             | Open autocomplete                           |
| ⌘D                 | Select the next occurrence                  |
| ⌘⇧L                | Select all occurrences                      |
| F3 / ⌘G, ⇧F3 / ⌘⇧G | Next / previous match                       |
| ⌘⌥G                | Go to line                                  |
| ⌘/                 | Comment or uncomment lines                  |
| ⌥↑ / ⌥↓            | Move line up / down                         |
| ⇧⌥↑ / ⇧⌥↓          | Copy line up / down                         |
| ⇧⌘K                | Delete line                                 |
| ⌘[ / ⌘]            | Indent less / more                          |
| ⇧⌘\\               | Jump to the matching bracket                |
| ⌘Z, ⇧⌘Z            | Undo, redo                                  |
| Esc                | Close autocomplete or search, single cursor |

## Elsewhere

| Where       | Keys       | Action                |
| ----------- | ---------- | --------------------- |
| Tab bar     | Home / End | First / last tab      |
| Tab bar     | Enter      | Rename tab            |
| Schema tree | ⌘F         | Search loaded objects |
| Result      | ⌘F         | Filter the result     |
| Cell editor | ⌘Enter     | Apply the value       |
